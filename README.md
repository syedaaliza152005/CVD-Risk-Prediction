# CardioCare — Cardiovascular Disease Prediction Using Machine Learning

CardioCare is an end-to-end machine learning mini-project that predicts cardiovascular disease outcomes from patient health data. It implements and compares five classification algorithms and deploys the selected model through an interactive Streamlit dashboard.

**Live Demo:** https://cardiocare-cvd.streamlit.app/

## Key Highlights

- Implemented and compared five machine learning classification algorithms.
- Evaluated models using accuracy, precision, recall, and F1-score.
- Selected Random Forest based on its performance on the evaluation dataset.
- Integrated the trained model and scaler into a Streamlit application.
- Developed an interactive interface for entering health parameters and viewing prediction results.

## Objectives

- Explore and understand cardiovascular disease data.
- Perform data preprocessing and exploratory data analysis (EDA).
- Train and compare multiple classification algorithms.
- Evaluate model performance using classification metrics.
- Deploy the selected model through a web-based dashboard.

## Dataset

- **Dataset:** Cardiovascular Disease Dataset
- **Total Records:** 1,000
- **Input Features:** 12
- **Target Variable:** `target`
- **Problem Type:** Binary Classification

The dataset contains demographic, clinical, and health-related attributes, including age, gender, chest pain, resting blood pressure, serum cholesterol, maximum heart rate, and exercise-induced angina.

The `patientid` column is excluded from model training because it serves as an identifier rather than a predictive feature.

## Machine Learning Models

Five classification algorithms were implemented and evaluated:

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)

## Model Evaluation and Results

The models were evaluated using accuracy, precision, recall, and F1-score.

| Algorithm | Accuracy | F1-Score |
|---|---:|---:|
| Logistic Regression | 98.00% | 98.29% |
| Decision Tree | 97.50% | 97.82% |
| Random Forest | 98.50% | 98.71% |
| K-Nearest Neighbors (KNN) | 91.50% | 92.70% |
| Support Vector Machine (SVM) | 97.00% | 97.46% |

**Selected Model: Random Forest**

Random Forest achieved the highest accuracy (98.50%) and F1-score (98.71%) among the five evaluated models. It was therefore selected for integration into the Streamlit dashboard.

These metrics reflect performance on the project's evaluation dataset and do not establish clinical validity or real-world generalization.

## Run Locally

### Prerequisites

Python and pip must be installed on your system.

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the project directory

```bash
cd <YOUR_PROJECT_FOLDER>
```

### 3. Install dependencies

```bash
pip install pandas numpy scikit-learn matplotlib seaborn streamlit joblib
```

### 4. Launch the application

```bash
streamlit run app.py
```

Replace `app.py` with the actual application filename if necessary. Ensure that all required model, scaler, and other application files are present in their expected locations.
